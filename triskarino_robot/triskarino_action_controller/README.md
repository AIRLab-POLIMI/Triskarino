# Triskarino Action Controller (triskarino_action_controller)
This folder contains the leaves and trees (implemented using library py_trees) used to create autonomous behavior in the robot using behavior trees. An example of a working behavior tree is the autonomous_behavior_tree.py. Current working leaves include nodes to activate lights, move linearly and rotate for certain distances, angles and velocities and making sounds. 
There are also working implementation of scripts that generate velocity commands to follow the stick toy or to approach a person with chase_person.py and chase_toy.py
